## 🚀 Quick Start

### Prérequis

- Git
- Navigateur Web (moderne)
- Splunk ou Microsoft Sentinel (optionnel)
- Python 3.8+
- PowerShell 5.0+

### Installation

```bash
# 1. Cloner le repository
git clone https://github.com/lycan669/NUMIDIA-CYBER-RESILIENCE-CORPORATION.git
cd NUMIDIA-CYBER-RESILIENCE-CORPORATION

# 2. Consulter la page Event IDs Interactive
open pages/event-ids/index.html
# Ou : start pages/event-ids/index.html (Windows)
# Ou : xdg-open pages/event-ids/index.html (Linux)

# 3. Lire la documentation
cat docs/SETUP.md

# 4. Explorer les scripts Python
cd scripts/python
python3 log-parser.py --help

# 5. Consulter les queries SPL
cd ../../detections/spl
cat brute-force-detection.spl
