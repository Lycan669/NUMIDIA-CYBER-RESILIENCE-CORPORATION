\# 🤝 Contributing



Merci de vouloir contribuer !



\## Comment Contribuer



\### 1️⃣ Signaler un Bug



Ouvre une \[Issue](../../issues) et décris :

\- Quoi ? (Description)

\- Où ? (Fichier)

\- Erreur ? (Qu'est-ce qui ne va pas)



\### 2️⃣ Proposer une Amélioration



Ouvre une \[Issue](../../issues) avec "Feature Request" et décris :

\- Quoi ? (Nouvelle idée)

\- Pourquoi ? (Importance)



\### 3️⃣ Envoyer du Code / Documentation



\*\*Étapes simples :\*\*



```bash

\# 1. Fork ce repo

git clone https://github.com/TON\_PSEUDO/NUMIDIA-CYBER-RESILIENCE-CORPORATION.git

cd NUMIDIA-CYBER-RESILIENCE-CORPORATION



\# 2. Crée une branche

git checkout -b feature/ma-feature



\# 3. Fais tes changements

\# Ajoute des fichiers, modifie du contenu, etc.



\# 4. Commit

git add .

git commit -m "Add: description de ton changement"



\# 5. Push

git push origin feature/ma-feature



\# 6. Ouvre une Pull Request sur GitHub
